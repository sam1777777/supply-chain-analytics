# Supply-chain-analytics
Supply chain analytics project using pythons, SQL, SQLite and data visualization.
Project Overview

This project analyses supply chain and inventory data using Python, SQL, and SQLite to explore vendor performance, purchasing patterns, sales trends, and profitability.

# Objectives

Analyse vendor and brand performance.

Compare sales and purchasing activity.

Examine profit margins and sales-to-purchase ratios.

Investigate purchase quantities and unit purchase prices.

Identify insights that can support purchasing and supply chain decisions.

# Tools and Technologies

Python

Pandas and NumPy

SQL and SQLite

Jupyter Notebook

Matplotlib and Seaborn

# Project Workflow

Load source data into a SQLite database.

Prepare data for analysis.

Generate a vendor summary using Python and SQL.

Perform exploratory data analysis.

Analyse vendor performance and supply chain metrics.

Visualise patterns and identify potential business insights.

# Analysis Areas

Exploratory data analysis

Vendor performance analysis

Supply chain analysis

Sales and purchasing comparisons

Profit margin and purchasing metrics

# Main Project Files

The repository will contain the Python scripts and Jupyter notebooks used for data ingestion, exploratory analysis, vendor performance analysis, and supply chain analysis.
